     4→## Product Architecture (final decisions)
     5→- **Constraint**: Single Next.js page route `/` (SPA with Zustand view routing). All backend = `/api/*` routes.
     6→- **Stack**: Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui + Framer Motion + Prisma/SQLite + z-ai-web-dev-sdk (backend only).
     7→- **Design**: "Medical OS" premium dark-first theme — deep midnight navy, clinical cyan primary, amber/red severity, glass surfaces, large typography. Light mode supported.
     8→- **Views**: landing | onboarding | home | map | learn | questions | cases | revise | tutor | progress | roadmap | profile (+ concept explorer overlay + global search).
     9→- **Knowledge engine** (`src/lib/engine.ts`): Ebbinghaus forgetting curve (R = e^(-t/S)), per-concept KnowledgeState, spaced repetition (SM-2-lite), NEXT_BEST_ACTION scoring (recall risk + weakness + exam relevance + year match + error patterns).
    10→- **Content**: All-original educational content. Subjects per NMC CBME structure (19 subjects), concepts as graph nodes with typed edges, ~60 original MCQs, ~50 flashcards, 4+ clinical cases, confusion pairs, disease/drug/investigation deep dives.
    11→- **Task IDs**: 1 (schema), 1b (seed), 1c (libs), 1d (APIs), 2-a..2-f (parallel view subagents), 3 (shell wiring), 4 (QA), 5 (cron).
